# Ficha de proyecto

**Proyecto:** CRM de gestion comercial y operativa.

**Autor del portafolio:** Gaston Cabero.

**Objetivo:** centralizar el seguimiento de clientes y oportunidades, la planificacion del equipo y los documentos comerciales, con acceso controlado a reportes.

**Alcance del sistema original:** clientes y contactos, oportunidades y seguimiento, proformas y ventas, planificacion, agendas, fondos y rendiciones, visor de correos, permisos y aplicacion movil.

**Tecnologias del sistema original:** Python, Flask, PostgreSQL, Firebird, JavaScript, HTML/CSS, Docker y aplicacion movil Flutter.

**Aspectos tecnicos trabajados:** integracion entre datos actuales e historicos, consultas paginadas de correos, permisos por usuario, generacion de documentos y mantenimiento del despliegue.

**Contenido publico:** demo visual con registros sinteticos y funciones locales. No se entrega el codigo de produccion.

**Para presentar en una postulacion:**

> Desarrolle y mantuve un CRM de gestion comercial y operativa con clientes, oportunidades, planificacion, proformas, ventas, rendiciones y consulta de correos. Trabaje en integraciones con PostgreSQL y Firebird, permisos por usuario, documentos PDF y despliegue con Docker. El repositorio publico presenta una demo visual con datos ficticios; el backend de produccion es privado.

Esta ficha no atribuye cifras de usuarios, ingresos o mejoras porcentuales que no se hayan medido. La URL publica se obtiene al publicar el repositorio en GitHub Pages.
